WERSJA 2 — Jakub Kamiński, Sesje RPG
=====================================

ZAWARTOŚĆ:
- index.html — nowa strona główna
- o-mnie.html — przebudowana zakładka „O mnie”
- style.css — istniejące style wspólne (pozostaw)
- home.css — style nowej strony głównej i wspólnych elementów
- about.css — DODATKOWE style wyłącznie dla „O mnie”
- pozostałe podstrony HTML — dotychczasowe wersje, bez przebudowy
- logo-red.png, logo-pattern.png — Twoje grafiki
- images/ — zoptymalizowane fotografie stockowe przekazane w rozmowie

JAK URUCHOMIĆ:
1. Rozpakuj cały folder i otwórz plik index.html w przeglądarce.
2. Do aktualizacji istniejącego projektu zamień o-mnie.html oraz dodaj about.css.
3. Pozostaw style.css i home.css — nowa podstrona ładuje wszystkie trzy arkusze.
4. Skopiuj folder images/ obok plików HTML. Te same obrazy uzupełniają również
   wcześniej przygotowaną stronę główną.

UWAGI:

  dosłowny cytat. Link prowadzi do shorta wskazanego przez autora strony.
- Chris Perkins: polskie tłumaczenie wypowiedzi przytoczonej w książce
  Return of the Lazy Dungeon Master. Podano odnośnik do wydawcy.
- Gary Gygax: skrócone polskie tłumaczenie fragmentu wywiadu Game Developer.
- Zdjęcia stockowe nie przedstawiają Jakuba Kamińskiego.
- W sekcji twórczości nie dodano nieznanego tytułu publikacji ani linku DriveThruRPG.
- Blog pozostaje sekcją zapowiadaną na index.html; nie tworzy fikcyjnych wpisów.
- Wersja mobilna była sprawdzana na szerokości 390 px, komputerowa 1440 px.

Pliki gotowe do hostingu statycznego: nie trzeba instalować frameworków.
